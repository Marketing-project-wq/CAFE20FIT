# CoffeeStory backdrop photos

Drop real photos here; the site picks them up automatically (no code change). Until a file exists the 3D story
paints a placeholder in that location's colours. Settings (labels, focal points, lighting) are in
`tools/src/backdrops-config.js`.

| File | What | Size |
|---|---|---|
| `farm-far.avif` + `farm-far.webp` | Coffee farm, red cherries, morning light (licensed for commercial use) | 2560×1440, ≤ 250 KB |
| `farm-far-mobile.avif` + `.webp` | Same scene, separate 9:16 crop | 1080×1920, ≤ 150 KB |
| `roastery-far…` | Drum roaster, burlap sacks | as above |
| `bar-far…` | The real 20FIT Cafe bar: espresso machine, grinder | as above |
| `arena-far…` | The real 20FIT Arena with the lights on | as above |
| `<location>-mid.png` / `.webp` (+ `-mobile`) | Optional cut-out with alpha (branch, espresso machine, light rig) | ≤ 150 KB |

Keep the right-centre (where the cup sits on wide screens) and bottom-left (text) calm. Grade all photos as one
family: a little more contrast, saturation −10–15 %, warm shadows, no blown highlights.
