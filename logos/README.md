# Payment logos

Shown on the checkout's payment method list.

- `visa.svg`, `jcb.svg`: official marks from [simple-icons](https://simpleicons.org) (CC0).
- `mastercard.svg`: the standard Mastercard circles mark.
- `qris.svg`, `gopay.svg`, `ovo.svg`, `shopeepay.svg`, `gpn.svg`, `bca.svg`,
  `mandiri.svg`, `bni.svg`, `bri.svg`: **placeholder wordmarks**. Replace each
  with the official logo file (from your payment provider's brand kit) using the
  same filename; no code change is needed.
