# Payment logos

Shown on the checkout's payment method list, the e-wallet / VA pickers, the
"Confirm your order" modal and the payment page. Every logo is drawn in the same
fixed box (80×32, centred, `object-fit: contain`), so files may have any aspect ratio.

- `ovo.svg`: official OVO wordmark (Wikimedia Commons, "Logo ovo purple.svg").
- `shopeepay.svg`: official ShopeePay logo, taken from shopeepay.co.id.
- `visa.svg`, `jcb.svg`: official marks from [simple-icons](https://simpleicons.org) (CC0).
- `mastercard.svg`: the standard Mastercard circles mark.
- `qris.png`, `bca.png`, `bni.png`, `bri.png`, `mandiri.webp`, `visa-mastercard.webp`:
  raster marks in use.
- `qris.svg`, `gopay.svg`, `gpn.svg`, `bca.svg`, `mandiri.svg`, `bni.svg`, `bri.svg`:
  **placeholder wordmarks** (not shown). Replace with the official file from the
  payment provider's brand kit using the same filename.
